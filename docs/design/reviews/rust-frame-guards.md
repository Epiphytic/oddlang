# Frame preflight source recovery review

Claude CLI auto mode reviewed the proposed preflight proof. It requested a case where both guards fail, exact named error checks, distinct decode order, standard shared-reference ordering, proof of lossless byte-count widening, and local function identity. The implementation checks the two failure channels independently, requires the checked helper's error type to match the encoder's error type, and limits the supported helper shapes to compiler-resolved pure operations. The unrelated witness independently predicts both priority orders and tests unsupported call effects or conversions.

The implementation review found no blocking findings. The native verifier qualified nine rules across seven variants with 72 rows on macOS ARM64. The source mutation reversed only the two Data encoder checks. Three overlapping failures changed from Limit to Offset. The independent caller also checked valid bytes and the separate decoder order. The companion review confirmed the proof structure and requested the full replay receipt, which is included in the reviewed release.
