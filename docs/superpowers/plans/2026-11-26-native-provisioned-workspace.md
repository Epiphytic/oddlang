# Native provisioned workspace implementation plan

**Goal** Assemble the independently reviewed copy protocol and encrypted profile initializer into the same source-free native workspace as foreground ownership and status.

**Architecture** The companion release manifest pins the core, stream and native packages and a root Cargo lock. The release gate stages those graph inputs, the prebuilt compiler and pinned external dependencies. Original sources, executables and oracles enter only during later qualification.

## Work

- [ ] Compose generic provider registration and parser bindings from the foreground, copy frame and file-profile revisions. Qualify their unrelated fixtures and review the combined framework.
- [ ] Seal the combined companion workspace. Preserve the core member, verify all pinned graph and generated inventories, and compare dependency sources to the exact original lock.
- [ ] Build locked release artifacts inside macOS ARM64 and Linux ARM64 isolation. Preserve existing parser, discovery, lease, actual TLS and crash recovery evidence.
- [ ] Cross all initializer, daemon and client choices using real local file-backed profiles. Check identity, private files and preserved credentials, and observe an actual held TLS attempt on each startup.
- [ ] Run every unchanged upstream stream test on the combined library and keep the independent exact frame checks. Record the two platform receipts and review the companion release.
