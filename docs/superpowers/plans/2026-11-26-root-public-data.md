# Standalone public data at the Rust crate root

The finite-error profile also supports unit domains with an absent result
alias. Its root recovery accepts a pinned ordinary public enum whose standard
Debug and thiserror derives name exact literal diagnoses. Error variants keep
ordinary Rust declaration order and have no source chain. It accepts
`#![cfg(unix)]` as a source profile boundary.

The public-record projection admits Debug as an exact declared capability. A
native overlay can flatten one alias-free logical module, so the package
assembler can re-export the selected records at its crate root. Root recovery
checks pinned public structs and ordinary source paths with distinct
declaration IDs. Both crate-root profiles reject local item macros and
aliases or impls involving the selected types. Native witnesses establish
external name resolution and verify the concrete public capabilities.
